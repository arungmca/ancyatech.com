# Service copy draft — Web Design (UI/UX)

## Working title
Web design that starts from the decision path, not the template.

## Narrative summary
- The page should focus on business decisions: what is sold, who it is for, what it costs, and the next step.
- Visual layouts are developed alongside accessibility and performance requirements, not after.
- The founder reviews every step directly; there is no hand-off illusion to emulate.
- Content remains grounded. No invented awards, client logos, or guaranteed ranking language.

## Technical position
- HTML/CSS-only component system first, with optional enhancements later.
- Mobile-first layout with explicit dimensions, semantic headings, and keyboard-visible controls.
- Progressive enhancement for forms and service interactions.
- One shared stylesheet and one shared behaviour file.

## Required diagrams
- User journey / decision map
- Component-level breakdown of the service page layout
- Deployment flow from review to Cloudflare Workers Assets
