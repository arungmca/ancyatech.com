# Journal draft — Web design is a decision process, not a deliverable

## Working title
Start from the decision path, not the template.

## Narrative summary
- Describe why visual templates alone fail to convert.
- Explain the four decisions that define a successful layout.
- Emphasize progressive enhancement, accessibility, and honest handover.
- Keep all claims grounded; avoid invented metrics.

## Technical position
- HTML/CSS-first design system
- Responsive layouts as a design requirement, not a retrofit
- No placeholder-only labels, no broken anchors, and no interactive confusion
- Component library reuse before bespoke styling

## Required visual (Mermaid or ASCII)
- Decision flow
- Component library structure
- Preview-to-production deployment boundary
