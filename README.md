# ancyatech.com

The Ancya Tech marketing site: a static site generated with **Eleventy (11ty)** from
`src/`, deployed to **Cloudflare Workers Static Assets**, with a small Worker handling
`POST /api/contact` through Resend.

`public/` is build output. Never edit it by hand.

## Stack

- Eleventy 3 for layouts, partials, data and page templates.
- Plain CSS (custom properties and component classes, no framework) and small ES modules.
- Cloudflare Workers Static Assets for hosting plus a Worker for the contact endpoint.
- GitHub Actions for validation, with build-based CI and the deploy job being wired.
- Nunjucks page templates and JSON data files; no Markdown content layer yet.

## Prerequisites

- Node.js 22 or newer (matches CI).
- npm (use `npm ci` for a reproducible install).
- Python 3 for the link and structural accessibility check scripts.
- A Cloudflare account with Wrangler access for deploys.
- A Resend API key for live contact-form delivery.

## Structure

```

├─ _includes/                Nunjucks layouts and partials
│  ├─ base.njk               document shell: head, sprite, header, footer, scripts
│  ├─ head.njk               meta, canonical, Open Graph and JSON-LD
│  ├─ header.njk · footer.njk
│  ├─ legal.njk              legal-page layout
│  ├─ sprite.njk             single source for the inline SVG symbol sheet
│  └─ cookie.njk
├─ _data/                    site metadata (URL, contact details, analytics, social image)
├─ assets/
│  ├─ css/                   base.css (tokens + reset) · main.css · legal.css
│  ├─ js/                    modules under src/assets/js/ (site, consent)
│  └─ img/ · svg/ · favicons/ · social/
├─ *.njk                     one template per page (index, about, work, journal, services, legal, 404)
├─ _headers                  Cloudflare response headers: CSP, HSTS, frame, referrer, cache
├─ robots.txt · sitemap.xml · site.webmanifest
public/                      generated by `npm run build` — do not hand-edit
worker/index.js              /api/contact handler (validation, rate limit, Resend)
tests/worker/                Worker endpoint tests (node:test)
scripts/                     check_links.py · check_a11y.py · test_a11y.sh
docs/                        contributor documentation and the design system
├─ DESIGN_SPEC.md            design and build rules
├─ styleguide.html           rendered component reference
├─ ARCHITECTURE.md           source-to-output structure and hosting
├─ ROUTING.md · CONTACT_FORM.md · PREVIEW_DEPLOY.md
└─ PRODUCTION_TODO.md · RELEASE_CHECKLIST.md · CHANGELOG.md

wrangler.jsonc · package.json · .github/workflows/ci.yml
```

## Install

```bash
npm ci
```

Copy `.dev.vars.example` to `.dev.vars` and fill in `RESEND_API_KEY` only when you need
live form delivery locally. `.dev.vars` is ignored by git.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Local development server with the Cloudflare Worker runtime. |
| `npm run build` | Builds Eleventy and publishes the site to `public/`. |
| `npm run check` | Checks every local link in the generated site and docs. |
| `npm run check:a11y` | Browserless structural accessibility checks (landmarks, H1s, alt text, accessible names). |
| `npm run lint:html` | Validates generated HTML with html-validate. |
| `npm run lint:css` | Lints the CSS with stylelint. |
| `npm run lint:js` | Lints JavaScript with ESLint. |
| `npm test` | Runs the Worker unit tests with `node:test`. |
| `npm run test:a11y` | Runs axe against rendered pages (requires Chrome/chromedriver). |
| `npm run deploy` | Deploys the Worker and the `public/` assets to Cloudflare. |

Run `npm run build` before any check that reads `public/`. `npm run dev` builds once and
then serves the site through Wrangler (normally `http://localhost:8787/`).

> The Eleventy migration is being completed on `v2`. `build`, `dev` and `test:worker`
> exist; the lint and `npm test` aliases are still being wired. Remaining work is tracked
> in [`docs/PRODUCTION_TODO.md`](docs/PRODUCTION_TODO.md).

## Content editing workflow

1. Edit the page template in `src/*.njk`; never edit `public/*.html`.
2. Change shared chrome (head, header, footer, cookie banner, SVG sprite) in
   `src/_includes/`. A nav change must only happen there.
3. Change repeated site metadata in `src/_data/site.json`. Navigation lives in
   `src/_includes/header.njk`; footer links live in `src/_includes/footer.njk`.
4. Add or change styles in `src/assets/css/`; tokens and reset live in `base.css`,
   components in `main.css`, legal-page styles in `legal.css`.
5. Put page behaviour in `src/assets/js/` modules. Do not add inline `<style>` blocks
   or per-page scripts that duplicate shared behaviour.
6. Add images under `src/assets/` with explicit dimensions and alt text.
7. Run `npm run build`, then `npm run check` and `npm run check:a11y` before committing.
8. Review `public/` only as build output; the source of truth is `src/`.

## Pages

| Route | Source | Status |
|---|---|---|
| `/` | `src/index.njk` | Live |
| `/about.html` | `src/about.njk` | Live |
| `/services-web-design.html` and five sibling service pages | `src/services-*.njk` | Live |
| `/journal.html`, `/journal-website-cost.html`, `/journal-design-decisions.html` | `src/journal*.njk` | Live |
| `/work.html`, `/work-foxtail-cafe.html` | `src/work*.njk` | Draft: `noindex`, excluded from the sitemap |
| `/privacy-policy.html`, `/terms-of-service.html`, `/cookie-policy.html` | `src/*-policy.njk`, `src/terms-of-service.njk` | Live |
| `/404.html` | `src/404.njk` | `noindex`, served for unknown paths |

Cloudflare serves extension-less URLs as well as `.html` (for example `/about` and
`/about.html`). See [`docs/ROUTING.md`](docs/ROUTING.md) for the full mapping.

## Design system

- [`docs/DESIGN_SPEC.md`](docs/DESIGN_SPEC.md) is the contract for colour, type,
  components, motion, accessibility and performance.
- [`docs/styleguide.html`](docs/styleguide.html) renders every component with its code.
- Tokens and component CSS live in `src/assets/css/` and are the only source of truth;
  `public/assets/css/` is generated.

## Security headers and the Worker

All static response headers live in `src/_headers` (CSP, HSTS, `X-Content-Type-Options`,
`X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` and cache policy). The Worker
adds the same baseline headers to its responses; `/api/contact` is the only dynamic route.
See [`docs/CONTACT_FORM.md`](docs/CONTACT_FORM.md) for the endpoint contract and secrets.

## Deploy

```bash
npx wrangler secret put RESEND_API_KEY   # first deploy or key rotation
npm run deploy
```

`wrangler.jsonc` deploys `worker/index.js`, serves `./public` through the `ASSETS`
binding, uses `html_handling: "auto-trailing-slash"`, `not_found_handling: "404-page"`,
and binds `ancyatech.com` plus `www.ancyatech.com`. Preview URLs are enabled. Rollback
and launch steps are in [`docs/PREVIEW_DEPLOY.md`](docs/PREVIEW_DEPLOY.md) and
[`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md).
